🔹 1. Équations $y' = ay$ ▶

Forme générale : $y' = ay$, où $a$ est une constante réelle.

📌 Solutions

Les solutions sur $\mathbb{R}$ sont : $y(x) = C e^{ax}$ avec $C\in\mathbb{R}$.

Si on impose une condition initiale $y(x_0)=y_0$, la solution est unique : $y(x) = y_0 e^{a(x-x_0)}$.

📈 Signe de $a$ et comportement

Si $a > 0$, $|y| \to +\infty$ quand $x\to+\infty$ (croissance exponentielle).
Si $a < 0$, $y \to 0$ quand $x\to+\infty$ (décroissance exponentielle).

🔹 2. Équations $y' = ay + b$ ▶

Forme : $y' = ay + b$, avec $a \neq 0$.

📌 Solution générale

Solution de l'équation homogène $y_H = C e^{ax}$.
Solution particulière constante : $y_p = -\frac{b}{a}$ (car $y'_p = 0$).

Solution générale : $y(x) = C e^{ax} - \frac{b}{a}$

🔹 3. Second membre variable ▶

Méthode de variation de la constante : On cherche la solution sous la forme $y(x) = C(x) e^{ax}$, on injecte dans l'équation pour déterminer $C(x)$.

📐 Exemple

$y' - 2y = e^{x}$
Solution homogène $y_H = C e^{2x}$.
Variation : $y = C(x) e^{2x}$ donne $C'(x) = e^{-x}$, donc $C(x) = -e^{-x} + K$.
Solution générale : $y(x) = K e^{2x} - e^{x}$.

🔹 4. Équations $y'' + ay' + by = 0$ ▶

Équation caractéristique : $r^2 + ar + b = 0$.

📌 Solutions selon le discriminant

$\Delta > 0$ (racines réelles $r_1, r_2$) : $y = A e^{r_1 x} + B e^{r_2 x}$
$\Delta = 0$ (racine double $r$) : $y = (A + Bx) e^{r x}$
$\Delta < 0$ (racines $\alpha \pm i\beta$) : $y = e^{\alpha x}(A\cos\beta x + B\sin\beta x)$
